# DramaQueenAI

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

An AI-powered drama and entertainment app that generates dramatic narratives, storylines, and character interactions using large language models.

## Features

- AI-generated drama storylines and plot twists
- Character personality modeling and dialogue generation
- Entertainment-focused content creation pipeline
- Customizable drama intensity and genre settings

## Installation

```bash
git clone https://github.com/uerzer/dramaqueenai.git
cd dramaqueenai
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```

Configure your settings in `config.py` before running.

## Requirements

- Python 3.9+
- OpenAI API key (or compatible LLM provider)
